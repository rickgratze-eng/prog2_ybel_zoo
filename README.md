# prog2_ybel_zoo

Ein kleines Zoo-Management-System, das im Rahmen des Moduls **Programmieren 2** entwickelt wurde.

## Inhalte

Dieses Projekt demonstriert den Einsatz von:

- Sealed Interfaces
- Records
- Generics
- Stream API
- Logging mit `java.util.logging`

## Projektstruktur

- `zoo.animal` – Tierhierarchie
- `zoo.enclosure` – Generische Gehege
- `zoo` – Zoo-Verwaltung und Demo-Anwendung

## Build

```bash
./gradlew build
```
